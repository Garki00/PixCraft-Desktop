# PixCraft Desktop

> 将任意图片转化为 24×24 像素画，并自动在明日方舟游戏中完成填色。

## 功能概览

- 拖拽导入图片，强制 1:1 裁剪
- 6 种缩放算法 × 4 种取样算法 × 4 种量化算法 × 12 种滤镜，可自由组合
- 实时预览，参数调整即时重新生成
- 3 种下载格式：720×720 高清版 / 标号参考版 / 24×24 原始位图
- 自动填色：控制鼠标在明日方舟游戏中逐格完成填色
- 全局快捷键 **F7** 开始填色，**F8** 停止

## 使用流程

### 1. 导入图片

- 拖拽图片到虚线框，或点击选择文件
- 支持 JPG、PNG、WebP、GIF 等常见格式
- 透明区域自动填充为白色

### 2. 裁剪画面

- 拖动选框中心移动位置
- 拖动右下角方块调整大小（强制 1:1）
- 点击**确定裁剪**生成像素画

### 3. 查看与调整结果

勾选**查看颜色标号**可在色块上显示编号（1–40）并展示右侧图例。

右侧面板修改后实时重新生成：

| 选项 | 默认值 | 说明 |
|------|--------|------|
| 缩放算法 | 浏览器高质量 | 控制图片缩小方式；区域平均适合复杂图案 |
| 取样算法 | 均值取样 | 控制每个色块颜色取样方式 |
| 对比度 | 1.20 | 向右增强色彩对比 |
| 锐化强度 | 0.60 | 向右使边缘更清晰 |
| 量化算法 | Redmean | 颜色匹配方式；CIELAB 更接近人眼感知 |
| 滤镜 | 无 | 12 种风格可选 |

### 4. 下载图片

| 格式 | 尺寸 | 说明 |
|------|------|------|
| 普通下载 | 720×720 px | 带白色边框和网格线 |
| 标号版 | 1280×720 px | 含颜色编号和图例，用于手动填色参考 |
| 像素位图版 | 24×24 px | 纯色块原始位图，无边框 |

## 自动填色

**前置条件**

- 游戏处于**画像册绘画**页面
- 游戏分辨率设置为 **1920×1080**
- 游戏窗口可见，未最小化

### 使用步骤

1. 在结果页面点击**自动填色**进入填色页面
2. 确认右侧面板显示"已匹配：明日方舟"；若未匹配，点击**刷新窗口列表**或手动选择
3. 按需调整**跳过白色**和**绘制间隔**
4. 点击**开始填色**，或按全局快捷键 **F7**（推荐使用快捷键）
5. 填色期间点击**停止** 或按 **F8**随时中断

> **注意**：填色期间鼠标将被接管，光标会跟随填色进度移动。建议使用 **F8** 快捷键中断，而非移动鼠标干扰点击序列。

### 快捷键

| 按键 | 功能 |
|------|------|
| F7 | 开始填色（全局） |
| F8 | 停止填色（全局） |

### 填色选项

**跳过白色**：跳过调色板第 4 号颜色（纯白 `[255,255,255]`），节省画面以白色为主时的填色时间。

**绘制间隔**：每次点击色块后的等待时间（0–1000 ms，默认 0）。游戏响应慢或出现漏点时可设为 50–200 ms。

### 日志格式

```
开始填色…
129/576-[220,210,200]
130/576-[220,210,200]
填色完成
```

每行颜色与当前填入颜色一致，便于实时确认进度。

## 常见问题

**点击位置不准确**

检查游戏分辨率是否为 1920×1080，窗口未被缩放。可适当调大绘制间隔。

**找不到明日方舟窗口**

确保游戏已启动且未最小化，点击**刷新窗口列表**。仍无法检测时使用下拉列表手动选择。

**nut-js 相关报错**

运行 `npm install` 确保依赖安装完整。
